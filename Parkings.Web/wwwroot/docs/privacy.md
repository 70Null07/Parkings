# Политика конфиденциальности SmartParkings

**Последнее обновление:** март 2026 г.

## 1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») описывает, какие персональные данные собирает сервис SmartParkings (smartparkings.ru), как они используются, хранятся и защищаются.

Используя Сервис, вы даёте согласие на обработку ваших данных в соответствии с настоящей Политикой.

---

## 2. Какие данные мы собираем

### 2.1. Данные, предоставляемые пользователем при регистрации

- Имя пользователя - идентификация в системе
- Адрес электронной почты - подтверждение регистрации, восстановление пароля, уведомления
- Пароль - аутентификация в системе

### 2.2. Данные о парковках

При добавлении парковки пользователь предоставляет: название, адрес, географические координаты (широта/долгота), URL видеопотока.

### 2.3. Данные, собираемые автоматически

- IP-адрес при обращении к Сервису;
- техническая информация о сессии (JWT-токен, время подключения);
- история загруженности парковок (количество свободных и занятых мест, временные метки).

### 2.4. Сообщения

Тексты сообщений, направляемых через встроенный мессенджер между пользователями.

---

## 3. Как мы используем данные

Собранные данные используются исключительно для:

- предоставления функциональности Сервиса (отображение карты, управление парковками, мессенджер);
- подтверждения регистрации и восстановления доступа к учётной записи;
- отправки уведомлений, связанных с безопасностью учётной записи (смена пароля, смена email);
- обеспечения безопасности и предотвращения злоупотреблений;
- формирования обезличенной статистики загруженности парковок.

Мы **не используем** ваши данные для:
- таргетированной рекламы;
- передачи третьим лицам в коммерческих целях;
- автоматизированного принятия решений, затрагивающих права пользователей.

---

## 4. Хранение данных

4.1. Данные хранятся на сервере в базе данных Microsoft SQL Server.

4.2. Пароли хранятся исключительно в виде хэша (bcrypt). Оригинальный пароль восстановить невозможно.

4.3. Чувствительные данные зашифрованы с использованием AES-256.

4.4. Данные хранятся в течение всего срока существования учётной записи, а также в течение 30 дней после её удаления — для возможности восстановления.

4.5. История загруженности парковок хранится без ограничений срока, поскольку является обезличенной статистикой.

---

## 5. Видеоданные

5.1. Сервис подключается к видеопотокам камер исключительно для анализа загруженности парковочных мест.

5.2. Видеозаписи **не сохраняются**. Система обрабатывает один кадр в момент анализа и немедленно его удаляет из оперативной памяти.

5.3. Результатом обработки является только число занятых и свободных мест — без каких-либо биометрических данных, лиц или номерных знаков.

---

## 6. Передача данных третьим лицам

Мы не передаём ваши персональные данные третьим лицам, за исключением следующих случаев:

- **Yandex SmartCaptcha** — при регистрации для проверки токена капчи передаётся IP-адрес и токен (данные обрабатываются согласно политике Яндекса);
- **SMTP-провайдер** — для отправки email-уведомлений передаётся адрес электронной почты получателя;
- по требованию уполномоченных органов в случаях, предусмотренных законодательством Российской Федерации.

---

## 7. Безопасность

Для защиты данных применяются следующие меры:

- передача данных по зашифрованному каналу HTTPS (TLS);
- аутентификация на основе JWT-токенов с ограниченным сроком действия (14 дней);
- хэширование паролей (bcrypt);
- ролевая модель доступа (пользователь / администратор / суперадминистратор);
- возможность блокировки учётных записей при подозрительной активности.

Несмотря на принимаемые меры, ни одна система не может гарантировать абсолютную безопасность передачи данных через интернет.

---

## 8. Права пользователя

В соответствии с законодательством вы вправе:

- **получить информацию** о хранящихся персональных данных — обратитесь на support@smartparkings.ru;
- **изменить** email и пароль — в разделе «Профиль»;
- **удалить учётную запись** — обратившись к администрации; данные будут удалены в течение 30 дней;
- **отозвать согласие** на обработку данных — путём удаления учётной записи.

---

## 9. Файлы cookie

Сервис использует только технически необходимые данные в локальном хранилище браузера.
Данные не передаются на сторонние серверы и используются исключительно для работы интерфейса.

---

## 10. Открытый исходный код

Поскольку SmartParkings является open-source проектом, исходный код обработки данных доступен для изучения. Это обеспечивает прозрачность в отношении того, как именно обрабатываются ваши данные.

---

## 11. Изменение политики

Мы вправе обновлять настоящую Политику. При существенных изменениях пользователи будут уведомлены по электронной почте. Актуальная версия всегда доступна по адресу smartparkings.ru/privacy.

---

## 12. Контакты

По вопросам обработки персональных данных обращайтесь: **support@smartparkings.ru**
