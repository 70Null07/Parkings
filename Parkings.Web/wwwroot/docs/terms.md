# Условия использования SmartParkings

**Последнее обновление:** март 2026 г.

## 1. Общие положения

Настоящие Условия использования (далее — «Условия») регулируют порядок использования сервиса SmartParkings (далее — «Сервис»), доступного по адресу smartparkings.ru, а также связанных программных интерфейсов и мобильных приложений.

SmartParkings является открытым проектом (open-source). Исходный код доступен для изучения и самостоятельного развёртывания. Использование Сервиса означает полное и безоговорочное принятие настоящих Условий.

---

## 2. Описание сервиса

SmartParkings предоставляет следующие возможности:

- просмотр публичной карты парковок с информацией о загруженности в режиме реального времени;
- регистрация и управление собственными парковками, включая разметку парковочных мест и настройку видеопотоков;
- автоматическое определение занятости мест с помощью компьютерного зрения (YOLOv10);
- просмотр истории загруженности парковок;
- добавление парковок в избранное и создание зон поиска на карте;
- обмен сообщениями между пользователями по вопросам парковок.

## 3. Регистрация и учётная запись

3.1. Для доступа к расширенным функциям необходима регистрация с указанием имени пользователя, адреса электронной почты и пароля.

3.2. При регистрации пользователь обязан предоставить достоверные сведения.

3.3. Пользователь несёт ответственность за сохранность своих учётных данных и все действия, совершённые под его учётной записью.

3.4. Пользователь обязуется незамедлительно уведомить администрацию Сервиса о любом несанкционированном доступе к его учётной записи.

3.5. Администрация вправе заблокировать или удалить учётную запись при нарушении настоящих Условий.

## 4. Правила использования

Пользователю запрещается:

- публиковать ложные сведения о парковках, их местоположении или загруженности;
- использовать Сервис для рассылки спама, нежелательных сообщений или рекламы;
- предпринимать попытки несанкционированного доступа к системе, данным других пользователей или видеопотокам;
- добавлять видеопотоки, на использование которых у пользователя нет прав;
- использовать автоматические средства для массового создания учётных записей или парковок;
- совершать действия, нарушающие работу Сервиса или создающие избыточную нагрузку на инфраструктуру.

6.1. Сервис позволяет владельцам парковок подключать видеопотоки с камер для автоматического определения загруженности мест.

6.2. Владелец парковки самостоятельно обеспечивает соответствие видеонаблюдения требованиям законодательства о персональных данных и информировании граждан о ведении съёмки.

6.3. Сервис обрабатывает видеоизображения исключительно в целях определения наличия транспортных средств. Видеозаписи не хранятся — используется только текущий кадр в момент анализа.

6.4. Пользователи не вправе подключать видеопотоки, направленные на частные пространства или позволяющие идентифицировать личность граждан.
